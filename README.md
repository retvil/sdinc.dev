# SDINC

[sdinc.dev](https://sdinc.dev) — персональный сайт-прибор.

Ретрофутуристический интерфейс в эстетике Pip-Boy (Fallout): профиль,
проекты, связи. Статичный сайт, деплой на GitHub Pages.

## Безопасность
Сайт статический, без форм ввода личных данных и без авторизации — низкая
цель для атаки. Зафиксировано решение **принять риск** по HTTP security-заголовкам:
на GitHub Pages они не применяются (Pages не читает `_headers`), поэтому в
прод-среде отсутствуют `X-Frame-Options` / `X-Content-Type-Options` / CSP.
Это осознанный выбор для личного портфолио, а не упущение.

Желаемый набор заголовков закреплён как единый источник истины в
[`public/_headers`](public/_headers) (инертен на Pages). Как только сайт
поставят за фронт, читающий эти заголовки (Cloudflare Transform Rules /
Caddy / Worker), достаточно применить этот файл — кодовые правки не нужны.

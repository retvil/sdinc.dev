# Инструкция по установке и проверке

Этот архив содержит полные исправленные файлы для репозитория `retvil/sdinc.dev` на базе коммита `2adede600b68ca3b8d9e64c83a3071052f236688`.

## 1. Подготовка
1. Открой папку локального репозитория (`sdinc.dev`).
2. Убедись, что рабочее дерево чистое или изменения сохранены (`git status`).

## 2. Установка файлов
Скопируй содержимое папки `files/` из архива в корень репозитория с заменой:
- `files/src/styles/effects.css` → `src/styles/effects.css`
- `files/src/styles/projects.css` → `src/styles/projects.css`

## 3. Проверка локально
Выполни команды:
```bash
npm install
npm run build
npm run test
npm run preview
```

Открой сайт в браузере и проверь:
1. Демонстрации «Видео- и аудиоаналитика», «Игровые проекты», «Аналитика звонков», «Автоматизация коротких видео» — ничего не обрезается, прокрутка работает, кнопка «Начать заново» и пояснения доступны.
2. При ширине окна около 1024 px подписи и кнопки остаются читаемыми (минимум 10–11 px).
3. Сканлайн-текстура дисплея отображается без конфликта с нижней навигацией.

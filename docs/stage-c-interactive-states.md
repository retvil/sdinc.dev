## Исправление этапа C

Дефект: базовый `outline` рисовал прямоугольную рамку клавиатурного фокуса
по границам вырезки узла — вопреки требованию «подсветка по форме элемента».

Фикс (`src/styles/global.css`): `outline: none` для
`.node-control/.open-control/.tab-control:focus-visible`; фокус индексируется
контурным кольцом/рамкой `::before` (цвет `#d3dda5`). Каскадная деталь:
редакторское правило `.control:focus-visible` ниже по файлу пере-включало
прямоугольник — супрессор перенесён в конец файла, из редакторского правила
`.control` исключён. Для секций и регулятора прямоугольный outline сохранён
как a11y-фолбэк (форма их пластин близка к прямоугольной).

Файл: `src/styles/global.css` (единственное изменение этапа C).
Статичные ресурсы корпуса, стек, зависимости, конфигурация публикации — не менялись.

## Нейтральная база (методика B)

- Метод: скриншот 1536×1024 CSS px, 100%, нейтральное состояние против
  референса, приведённого к 1536×1024 фильтром Lanczos; попиксельная
  средняя абсолютная ошибка RGB (шкала 0–255).
- База: **MAE_ALL = 1.201**, зона MOD 1.0 = 2.141. Повтор после этапа C:
  идентично (1.201 / 2.141) — регрессии нет.
- Оговорка (сформулирована пользователем, обязательна): низкие средние
  значения **не доказывают отсутствие всех локальных швов**; объяснение
  остаточной ошибки ресемплингом — рабочая гипотеза, не доказанный факт.
  Число диагностическое, не «процент сходства».
